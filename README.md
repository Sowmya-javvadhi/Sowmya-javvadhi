### 📊 [Kids Screentime Visualization — DV Screen Sense](https://github.com/Sowmya-javvadhi/Kids-screen-time-visualization)
Built an interactive Tableau dashboard using the Indian Kids Screentime 2025 dataset from Kaggle to visualize children's screen usage patterns.

---

### 📡 [Live Event Registration Tracking Dashboard](https://github.com/Sowmya-javvadhi/Live-Event-Registration-Tracking-Dashboard)
Built a real-time registration tracking dashboard using Base44 to monitor participant registrations for multiple technical events, with visual components for event-wise counts, daily trends, and summary statistics.
**Tech Stack:** `Base44`

---

### 🪪 [VisionID](https://github.com/Sowmya-javvadhi/VisionID)
OCR-based document intelligence application that extracts Aadhaar details from card images using Computer Vision, OCR, and intelligent parsing. Includes image quality validation, rotation correction, OCR-based text extraction, field extraction, JSON output generation, and OCR confidence analysis via a Streamlit UI.
**Tech Stack:** `Python` `Streamlit` `OpenCV` `EasyOCR` `Pillow` `NumPy`

---
